# Code of conduct

Kaia Reader follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read the full text at that link. The covenant applies to project spaces, including the repository, issues, pull requests and discussions.

Report conduct concerns privately to the maintainer through GitHub (https://github.com/Wildeax), or open a private security advisory on the repository if the report must stay confidential.
