# Review 1 findings (2026-10-13)

Independent review of the Rust crates by stronger-model reviewers, before the first Kobo build of the Rust app. Each finding has a fix status.

## Gestures and input (kaia-input, kaia-app, kaia-lua)

| ID | Severity | Finding | Status |
|---|---|---|---|
| G-H1 | High | App clock mixes scheduler time (from app start) with kernel event timestamps, so on a Kobo hold fires only at lift (`kaia-app/src/app.rs` "now" = max(scheduler.now, last_input)). | Fixed |
| G-H2 | High | Lua `ges` tables: multiswipe directions as array not string; pinch/spread/inward/outward axis in `axis` not `direction`; rotate `turn` not `direction`; `relative` missing on pans. | Fixed |
| G-M1 | Medium | Detector treats each touch sample as a frame; KOReader updates all slots per frame first. Rotate lost, two-finger pan values differ. Needs frame batching from the evdev decoder (SYN_REPORT) into the detector. | Fixed |
| G-L1 | Low | Two-finger midpoints round down; KOReader rounds half up. | Fixed |
| G-L2 | Low | hold_pan from inward or outward pan drops direction, span, start_span, end_pos. | Fixed |
| G-L3 | Low | No runtime setter for disable_double_tap and tap_interval_override (KOReader changes them per window, for example the keyboard). | Fixed |

## KOReader behavior drift (kaia-book, kaia-events, kaia-stats, kaia-luadata, kaia-id)

Compared against KOReader's Lua code and, where possible, by running both on the same input.

| ID | Severity | Finding | Status |
|---|---|---|---|
| K-H1 | High | EPUB highlight `pos1` points at the last selected character; KOReader points just after it (`base/cre.cpp:2186`). Imported KOReader highlights lose a character, and KOReader reads Kaia's highlights one character short. | Fixed |
| K-H2 | High | KOReader PDF positions are already at zoom 1, but `kaia-book/src/pos.rs` divides by `zoom` again, so highlights made at other zoom levels move toward the top left. | Fixed |
| K-H3 | High | The scheduler takes every due task off the queue before running any, so a task cannot cancel another task due in the same tick (`uimanager.lua:1003` pops one at a time). | Fixed |
| K-H4 | High | `Ctx` queues `send`, `broadcast`, `show` and `close`; KOReader runs them at once, so code that checks the result right after the call differs. Documented for the Lua layer; needs a decision for plugins. | Open |
| K-M1 | Medium | Annotations are stored in insertion order with a (page, y, x, id) sort; KOReader keeps them sorted by its own rule (bookmarks first on a page, xpointer compare, `pos1` tie-break) and binary searches them. | Partly fixed: KOReader order rule, but xpointers are compared in Rust, not by the engine |
| K-M2 | Medium | Chapter of an annotation uses the last TOC entry on or before the page; KOReader uses the first entry on the page and compares xpointers for EPUB. Bookmarks lack KOReader's `text = "in <chapter>"`. | Partly fixed: first entry on the page and bookmark text; EPUB xpointer compare needs the TOC xpointer from kaia-doc |
| K-M3 | Medium | Sidecar choice reads the first candidate that parses; KOReader takes the newest, skips empty tables, and checks legacy, history and `.kpdfview` files. Pre-2024 sidecars (`bookmarks` plus `highlight`) import nothing. | Fixed |
| K-M4 | Medium | Import drops `text_edited`, `pageref`, `pboxes`, `ext` and `note_format`, and turns line breaks in selected text into spaces. | Fixed |
| K-M5 | Medium | A gesture set to "Nothing" cannot be stored (empty entries are deleted); KOReader stores `{}` to swallow the gesture. Stored shape differs from KOReader's `gesture_fm` and `gesture_reader` sections. | Fixed |
| K-M6 | Medium | `read_or_init(key, false)` saves `false`; KOReader skips falsy defaults. | Fixed |
| K-M7 | Medium | `event_for` covers only part of `Dispatcher:execute`: no `ConfigChange` for configurable actions, no reader or paging filter, no batched updates, no `key` category. | Fixed |
| K-M8 | Medium | No per-window dithering and no function form of `setDirty` in the Rust window stack. | Fixed |
| K-M9 | Medium | Statistics book lookup misses old PDF rows whose title and authors end in a NUL, so a shared database gets a second row for the same book. The `start_book` key contract is not written down. | Fixed |
| K-L1 | Low | kaia-book: times written in UTC (KOReader uses local time); sidecar path differs for dots in folder names and names like `.foo`. | Fixed |
| K-L2 | Low | kaia-luadata: mixed key types sort differently from KOReader; `\ddd` escapes that make invalid UTF-8 fail the parse; no `.old` backup on write. | Fixed |
| K-L3 | Low | kaia-id: `filename_md5` hashes a lossy UTF-8 copy of non-UTF-8 names. | Fixed |
| K-L4 | Low | kaia-stats: new rows get `'N/A'` series and language and zero counts; `pages = 0` accepted; `freeze_finished_books`, `min_sec` and `max_sec` not read; WAL import leaves `-shm` and `-wal` files; a newer `user_version` is refused where KOReader warns. | Fixed |
