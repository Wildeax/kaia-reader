# Kaia reading fonts

Reading fonts that Kaia adds to KOReader's set, for readers with dyslexia or
low vision. Both are under the SIL Open Font License 1.1. Each folder keeps its
license file. The files are unmodified copies.

| Folder | Font | Source | Commit |
|---|---|---|---|
| `atkinson-hyperlegible` | Atkinson Hyperlegible 1.006, by the Braille Institute of America | https://github.com/googlefonts/atkinson-hyperlegible (`fonts/ttf`) | `1cb311624b2ddf88e9e37873999d165a8cd28b46` |
| `opendyslexic` | OpenDyslexic, by Abbie Gonzalez | https://github.com/antijingoist/opendyslexic (`compiled`) | `1824da5c0e41dc3e13ffc7f3a636dcaf695d61b7` |

OpenDyslexic is a Reserved Font Name. A modified copy must use another name.
